# Plan por sprints

## Sprint 0 — base local (implementado)

Frontend, login, rutas API privadas, galería por usuario, adaptador FLUX.2-pro y pruebas locales. Queda pendiente la prueba real de generación con una clave nueva de Foundry.

## Sprint 1 — staging

Elegir hosting y almacenamiento privado persistente. Crear entornos separados, TLS, variables seguras y verificación de cabeceras/cookies. Probar solo recursos propios.

## Sprint 2 — endurecimiento y telemetría

Cuotas distribuidas, presupuesto por usuario, limpieza de sesiones, backups, eventos normalizados, retención y privacidad. Auditar dependencias y configurar CI.

## Sprint 3 — SOC

Exportar eventos disponibles a Splunk, crear detecciones verificadas y medir falsos positivos. Documentar MITRE ATT&CK solo donde aplique.

## Sprint 4 — Jev

Definir contrato de decisión estructurada y evaluación. Jev clasifica y enruta; el código controla el flujo. Acciones sensibles requieren aprobación humana.
